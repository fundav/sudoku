# Sudoku
A sudoku solver.
I started this project in 2024 but most major changes happened at the end of 2025.
It uses the python selenium library as well as other built-in ones.
Sudoku techniques utlized are common sudoku Basics, intersections, forced Moves, pinned Squares, nSingles, nPairs, nTriples, nQuads

# How it works
No other input is needed from the user apart from running the code. When it is done it saves a screenshot of the puzzle.
However you can experiment with the date of the puzzle you would like to see solved by using the "solveSudoku" function.
Enter in a date as a string in the MM/DD format for example solveSudoku(3, "0125").
